# Feature: DS-119 Dashboard displaying the right components

As an admin user, I want to see the correct Dashboard so that I can reach the core Didaxis Studio areas from one place.

# Happy paths

Scenario: Navigate to the Dashboard
  Given I am logged in as admin
  When I navigate to the Dashboard page
  Then I see the Dashboard
  And I see the dashboard blocks: Programs, Calendar, Validation, AI Assist

Scenario: Successfully navigate to Program Page
  Given I am on the Dashboard page
  When I click the Programs card
  Then I navigate to the Programs page
  And I see the Programs page heading

Scenario: Successfully navigate to Calendar Page
  Given I am on the Dashboard page
  When I click the Calendar card
  Then I navigate to the Calendar page
  And I see the Calendar page heading

Scenario: Successfully navigate to Validation Page
  Given I am on the Dashboard page
  When I click the Validation card
  Then I navigate to the Validation page
  And I see the Validation page heading

Scenario: Successfully navigate to AI Assist Page
  Given I am on the Dashboard page
  When I click the AI Assist card
  Then I navigate to the AI Assist page
  And I see the AI Assist page heading

# Negative

Scenario: Dashboard card navigation should not leave the user on the Dashboard
  Given I am on the Dashboard page
  When I click the Programs card
  Then I should not remain on the Dashboard page
  And I should see the Programs page instead

# Edge cases

Scenario: Dashboard remains reachable after navigating away
  Given I am logged in as admin
  And I am on the Programs page
  When I click the Dashboard navigation item
  Then I navigate to the Dashboard page
  And I see the dashboard blocks: Programs, Calendar, Validation, AI Assist
